# LINE Rangers 커뮤니티 모니터 · 출처 및 운영 메모

## 공개 페이지와 자동 갱신

공개 사이트는 GitHub Pages에서 `index.html`과 `latest-cache.json`을 제공합니다. `.github/workflows/refresh-and-deploy.yml`이 매일 **오전 10:00 KST(01:00 UTC)**에 `server.py --refresh-only`를 실행하고 데이터를 다시 배포합니다. GitHub Actions 예약 실행은 지연되거나 누락될 수 있어 **10:17, 10:47, 11:17 KST**에 백업 실행을 등록했습니다. 백업 실행은 그날 09:45 이후 모든 출처의 수집이 성공한 경우 건너뛰고, 일부 출처가 실패했다면 다시 시도합니다. 워크플로의 `Run workflow`로 수동 실행도 가능합니다.

공개 페이지의 `최신 데이터 확인` 버튼은 이미 배포된 JSON을 다시 읽습니다. 수집 자체는 예약 작업에서 실행되며, 페이지를 열어 둔 경우 15분마다 새 JSON을 확인합니다. 오전 10:30 이후에도 오늘 자료가 없으면 화면에 수집 지연을 표시합니다. 출처 수집 실패 시 이전 글을 유지하고 출처 상태를 `이전 자료`로 표시합니다. 자동화 실행 기록은 GitHub Actions에서 확인할 수 있습니다. GitHub의 예약 실행은 시각을 보장하지 않으므로 백업 시각에도 누락이 반복되면 외부 스케줄러를 추가해야 합니다.

## 실행

프로젝트 폴더에서 다음 명령을 실행하고 `http://127.0.0.1:8765`를 엽니다.

```bash
python3 Codex/line-rangers-community-monitor/server.py
```

필요한 파이썬 패키지는 `beautifulsoup4`, `playwright`, `curl_cffi`, `pyyaml`이며, Playwright Chromium이 설치되어 있어야 합니다. 이 작업 환경에서는 설치 및 동작을 확인했습니다. 포트를 바꾸려면 `--port 8766`을 붙입니다.

국가와 이슈를 고르면 상단 반응 요약과 아래 출처 카드가 함께 바뀝니다. 출처 카드에는 **그 출처에서 실제로 수집한 해당 카테고리 글**과 원문 링크·한국어 한 줄 요약·감정 점이 나옵니다. 관련 글이 없으면 `관련 글 없음`으로 표시합니다. 파랑은 긍정, 빨강은 부정, 노랑은 중립 또는 혼합입니다. `확인 기록`은 이 브라우저의 localStorage에 저장됩니다. `index.html` 파일을 단독으로 열면 출처 목록은 보이지만 실시간 수집 API는 연결되지 않습니다.

## 자동 수집과 판정

- **태국:** Pantip의 `LINE Rangers` 검색을 최신순으로 열어 제목·미리보기·작성일을 수집합니다. Playwright 브라우저가 필요합니다.
- **대만:** 巴哈姆特 게시판에서 최근 글과 공개 본문을 수집합니다.
- **일본:** エスピーゲーム의 신규순 리뷰와 1–5점 별점을 수집합니다. 이 사이트에는 App Store 유입 리뷰도 포함됩니다.
- **한국:** 네이버 `라인레인저스 유저카페`의 공개 카페 검색 결과에서 제목·미리보기·표시 날짜를 수집합니다. 카페 원문 전체를 수집한 것으로 취급하지 않으며, 화면에 `검색 미리보기 기준`으로 구분합니다. 로그인·카페 가입이 필요한 글은 원문 열람이 제한될 수 있습니다.
- **태국 Facebook:** [LINE Rangers Thailand 유저 그룹](https://www.facebook.com/groups/1216791171685249/)의 공개 개별 글을 검색 결과에서 찾고, 공개 게시글 미리보기를 확인합니다. 계정 거래 광고를 반응에서 제외합니다.
- **대만 Facebook:** [LINE Rangers 銀河特攻隊 玩家攻略交流討論區](https://www.facebook.com/groups/385613083508950/)의 공개 개별 글을 같은 방식으로 확인합니다.
- **일본 X:** 공개 검색에서 일본 이용자 글의 URL을 찾고, 공개 게시글 본문과 작성일을 확인합니다. 공식 게임 계정과 후속작 `LINE おまかせレンジャー` 글은 이용자 반응 집계에서 제외합니다.
- 네이버의 `1주 전` 같은 상대 날짜는 수집일 기준으로 환산하고 `(추정)`을 붙입니다.
- Facebook의 날짜는 검색 결과 표시일이므로 `(추정)`을 붙입니다. Facebook 비공개 글과 X 비공개 글은 수집하지 않습니다. 해당 채널에서 공개 글을 확인하지 못하면 `관련 글 없음`으로 표시하며, 다른 채널의 글을 대신 보여주지 않습니다.
- 최근 **180일** 글만 집계하고, 서버는 **15분** 동안 결과를 캐시합니다. 화면도 15분마다 다시 요청하며 `지금 갱신`으로 즉시 요청할 수 있습니다.
- 일본 리뷰는 1–2점을 부정, 4–5점을 긍정, 3점을 중립으로 봅니다. 여러 주제를 다룬 리뷰는 제목의 중심 이슈에만 별점을 적용합니다. 태국·대만·한국은 명시적 평가 표현을 보수적으로 찾습니다. 정보글·모집글·도움 요청을 찬사로 세지 않습니다.
- 한 글이 여러 카테고리에 걸칠 수 있습니다. 각 카테고리에서 긍정·부정 합계가 **2건 미만이면 ‘자료 부족’**으로 표시합니다. 결과는 표본의 방향이며 전체 이용자의 대표 여론을 뜻하지 않습니다.
- 출처 수집에 실패하면 실패를 표시하고 이전 성공 자료가 있으면 `이전 자료`로 표시합니다. 새 글이 없다고 해서 자동으로 긍정이나 부정으로 표시하지 않습니다.

자동 번역·LLM 요약은 사용하지 않습니다. 한국어 한 줄 요약은 제목·수집 본문 또는 검색 미리보기에서 확인한 표현을 사전 규칙으로 풀어쓴 것입니다. 카테고리 요약은 글 수와 반복된 이슈 표현을 조합합니다. 자세한 판단에는 각 글의 원문과 맥락을 확인해야 합니다. 검색 링크만 제공하는 보조 채널은 `자동 수집 미연동 · 관련 글 없음`으로 표시하며, 다른 출처의 글을 해당 채널의 글처럼 옮겨 넣지 않습니다.

## 카테고리

- **콜라보·이벤트:** IP 선호, 보상, 복각, 참여 동기
- **가챠·상품:** 확률, 가격, 중복, 천장, 구매 판단
- **PvP·메타:** 캐릭터·장비 성능, 밸런스, 편성
- **신규·복귀:** 입문 가이드, 성장 난도, 캐치업
- **품질·CS:** 접속, 튕김, 계정, 결제, 고객지원
- **길드·소셜:** 모집, 친구, 협동, 커뮤니티 활동

Pantip과 네이버 검색은 일반 HTTP 요청이 차단될 수 있어 로컬 브라우저로 수집합니다. Facebook·X는 공개 검색에서 개별 글을 발견할 수 있을 때만 자동 감성 집계에 포함됩니다. Dcard·YouTube·디시인사이드는 원문 탐색 링크이며 자동 감성 집계에는 포함되지 않습니다.
